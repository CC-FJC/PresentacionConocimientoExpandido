02

Exploración

La restricción del celular

Un solo HTML

Sin librerías ni imágenes externas. Funciona con mala conexión.

Táctil

Nada depende del cursor. Botones de al menos 44 px.

Vertical

Diseño que se adapta al ancho de la pantalla.

Liviano

Modelos 3D de 2 MB como máximo, para teléfonos viejos.

RA como extra

La realidad aumentada solo funciona en equipos compatibles.

Sonido apagado

Encendido solo si el usuario lo pide.

Prompt inicial

Anatomía del prompt

ParteQué contienePor qué importa
1. Rol y públicoQuién usa el recurso y con qué nivel previoAjusta el lenguaje y la profundidad
2. Objetivo de aprendizajeLo que el estudiante debe entender al finalEvita una simulación vistosa pero sin propósito
3. ExperienciaQué ve, qué toca y cómo responde el recursoEs el diseño de la interacción
4. Contenido científicoValores y reglas correctos, dictados por el docenteLa IA escribe, el docente es la autoridad: reduce errores
5. Restricciones técnicasUn solo HTML, celular, sin internet, táctilPreviene la pantalla en blanco y lo que falla en el celular
6. EstéticaEstilo, contraste, idiomaEvita lo genérico y asegura legibilidad
7. EntregaQué devuelve y cómo se pruebaObtiene algo listo para abrir

Bloque 04 · No es solo prompts

Cuatro skills con reglas de dibujo

Animación

stick-scene

Figuras de palitos que explican un proceso. Propone 2–3 metáforas y revisa cada cuadro.

Canvas sin librerías · MIT

npx skills add nilbuild/stick-scene
Repositorio →
Modelo explorable

anatomy

La idea como máquina isométrica interactiva. Piezas sólidas, nada flotante, 40+ partes.

HTML + SVG · MIT · 30–90 min por figura

hermes skills install official/creative/anatomy
Documentación →
Simulación

microsim-generator

Simulaciones educativas: elige el motor según el concepto (p5.js, Chart.js, Plotly, mapas, redes, líneas de tiempo).

HTML para incrustar · ancho adaptable

npx skills add https://github.com/dmccreary/ibook-skills --skill microsim-generator
Ficha del skill →
Infografía

infographic-creator

Texto a infografía con ~200 plantillas: líneas de tiempo, mapas mentales, comparaciones, DOFA.

HTML + exporta SVG · AntV · MIT

npx skills add https://github.com/antvis/chart-visualization-skills --skill infographic-creator
Repositorio →

Formato abierto Agent Skills: se instalan en agentes con terminal o editor (Claude Code, Codex, Cursor, Gemini CLI…), no en el chat.
